# 买入判定 II 模块设计

## 背景

在现有「买入判定」（`/decision/buy-check`）保留不动的前提下，新增一个「买入判定 II」页面。与旧版「单原因 → 种类 → 位置」三步强联动不同，II 版把买入判断拆解为 6 个互相独立的维度，每个维度都可以不选，维度之间没有任何选项过滤或联动限制。

本次采用纯前端实现，不新增后端 API、数据库表或决策记录持久化，也不与持仓管理模块打通。

## 产品行为

页面标题为「买入判定 II」，副标题说明是六维独立打分、纯本地判断、不联网不查行情。

用户在 6 张维度卡片上自由勾选：

| 维度   | 选项                   | 多选                 |
| ------ | ---------------------- | -------------------- |
| 推荐   | 大V推荐、小V推荐       | 允许多选（分数叠加） |
| 因素   | 热点、潜伏             | 单选                 |
| 走势   | 暴跌、回调             | 单选                 |
| 知名度 | 龙头、二线、杂毛       | 单选                 |
| 类型   | 蓝筹、成长、周期、题材 | 单选                 |
| 位置   | 高位、中位、低位       | 单选                 |

约束：

- 所有维度都可以为空，单选维度再点一次已选按钮即取消选择。
- 至少勾选任意 1 项即触发判定；全部为空时结果区显示占位提示，不判定。
- 周期类型按成长一样处理（分数相同，描述按字面展示）。
- 旧版的「暴跌当日/次日」时机规则、潜伏/试水的专门表不再存在，位置高低只通过位置分体现。

判定结果展示与旧版一致：

- 判定档位：别买、观察、轻仓、正常、重仓、超重仓。
- 建议投入：0、1、2、4、6、8 万元，与档位一一对应。
- 结果色：别买红色，观察/轻仓警告色，正常品牌色，重仓/超重仓绿色。
- 进度条按建议投入除以 8 显示比例。
- 结果区额外显示本次总分。
- 档位对照表 6 行，当前命中行高亮。
- 提供「清空全部」按钮，一键恢复到全空状态。

## 判定规则

总分 = 所有已选因子的分数之和，映射沿用旧版 `mapScoreToLevel`（直接从 `buyDecisionRules.js` 导入复用）：0 及以下别买，1 观察，2 轻仓，3-4 正常，5-6 重仓，7 及以上超重仓。

因子分数表：

| 维度   | 选项与分数                       |
| ------ | -------------------------------- |
| 推荐   | 大V推荐 +4，小V推荐 +2           |
| 因素   | 热点 0，潜伏 0                   |
| 走势   | 暴跌 0，回调 +2                  |
| 知名度 | 龙头 +2，二线 -1，杂毛 -3        |
| 类型   | 蓝筹 +2，成长 0，周期 0，题材 -2 |
| 位置   | 高位 -2，中位 0，低位 +2         |

否决规则（优先于打分）：

- 位置为高位，且因素为热点或走势为回调（两者任一或同时）→ 直接判别买，固定文案「高位追热点/抢回调，接盘风险大，不碰。」
- 该规则只在「位置 = 高位」被显式勾选时生效；位置为空时不否决。

说明文案按已选因子拼接生成，格式「因子 + 因子 + …：建议X。」（打分得出别买时沿用旧版文案「这笔不划算，先不动。」；高位否决使用固定文案）。

## 前端结构

新增路由：

- `/decision/buy-check-ii`：页面「买入判定 II」，挂在现有「决策判定」菜单组下，排在「买入判定」之后。

新增文件：

- `src/views/decision/buyDecisionRules2.js`：维度与选项常量、分数表、否决规则、总分计算、档位映射调用。
- `src/views/decision/BuyDecisionII.vue`：页面交互和展示。
- `src/views/decision/buyDecisionRules2.test.js`：规则单元测试。
- `src/views/decision/BuyDecisionII.test.js`：页面组件测试。

修改文件：

- `src/router/routes.js`：新增子路由。
- `src/router/routes.test.js`：追加「买入判定 II」标题断言。

不修改：`BuyDecision.vue`、`buyDecisionRules.js`（仅被导入）、`codebook.js`、持仓管理相关模块、后端。

`BuyDecisionII.vue` 使用 Element Plus 组件，布局复刻旧版风格：6 张维度卡片 auto-fit 网格（推荐卡片按钮组支持多选叠加），结果区左窄右宽两列（档位对照表 + 判定结果），底部 `el-collapse`「这套判断的依据」说明计分表与高位否决规则。规则模块保持无 Vue 依赖，选项与分数全部来自规则模块，页面不定义第二套硬编码规则。模板预埋 `data-test` 属性供组件测试定位。

## 错误与边界

- 全部维度为空：不判定，结果区显示「请至少选择一项」类占位文案。
- 只选位置（如低位）：仍正常判定（低位 +2 → 轻仓）。
- 单选维度重复点击：取消选择，等同该维度为空。
- 推荐维度：大V、小V可同时勾选，分数叠加为 +6。
- 否决触发时不展示分数计算结果，直接输出别买与固定文案。
- 别买档位建议投入仍显示 0 万元。

## 验收

- 侧边栏「决策判定」下出现「买入判定」与「买入判定 II」两项，旧页面行为不变。
- 6 维度可任意组合勾选/取消，至少 1 项即出结果，全空显示占位。
- 推荐多选叠加、周期按成长计分、高位否决、分数边界（0/1/2/4/6/7）均有单元测试覆盖。
- 页面组件测试覆盖多选交互、否决触发与清空。
- `npm run check` 通过。
